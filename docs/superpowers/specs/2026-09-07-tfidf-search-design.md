# TF-IDF 检索设计

## 目标

用 TF-IDF 相似度替换当前的关键词包含判断，让用户输入一句问题后，程序返回相关度最高的最多三个资料段落。

## 保留内容

- 继续读取 `data` 文件夹中的所有 `.txt` 文件。
- 继续按空行切分段落。
- 继续使用当前的循环输入，并用 `q` 退出。
- 继续拒绝空输入。

## 检索流程

1. 使用 `TfidfVectorizer` 把所有资料段落和用户问题转换成数字向量。
2. 使用余弦相似度比较问题与每个段落。
3. 按相似度从高到低排序。
4. 只显示相似度大于零的前三个段落，并显示分数。
5. 没有有效结果时显示“没有找到相关内容”。

## 边界与错误处理

- `data` 中没有可用段落时，返回空结果，不让程序崩溃。
- 用户只输入空格时，提示关键词不能为空。
- 当前只处理 `.txt` 文件；PDF、Word 和向量数据库不在本次范围内。

## 验证

先编写一个最小自检：给定三个固定段落，查询“机器学习”，确认相关段落排在第一位。自检先失败，再实现最少代码使其通过。
